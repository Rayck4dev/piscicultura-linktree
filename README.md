olá# 🐟 Piscicultura Magrão Alevinos

Bem-vindo ao projeto **Piscicultura Linktree**, uma aplicação web moderna para apresentar catálogo de peixes, contatos e informações da piscicultura de forma simples e intuitiva.  
O objetivo é facilitar a comunicação com clientes e mostrar o catálogo atualizado de espécies disponíveis.

## 📖 Funcionalidades

- 📂 **Catálogo de Peixes** com imagens, vídeos e status de disponibilidade.
- 🔍 **Filtros inteligentes** para visualizar espécies disponíveis, em breve ou indisponíveis.
- 🎥 **Player de vídeo** integrado para mostrar os peixes em ação.
- 📱 **Menu flutuante** com acesso rápido ao WhatsApp e botão de voltar para Home.
- 🎨 **Design responsivo** com TailwindCSS, adaptado para desktop e mobile.
